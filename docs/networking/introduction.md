# Networking — Introduction

## What is a computer network?

A computer network is a collection of interconnected devices that
communicate and exchange data using agreed-upon rules called protocols.

Examples of networked devices include computers, smartphones, servers,
routers, and switches.

## Why does networking matter?

Networking enables devices and applications to communicate locally
and across the internet.

It is fundamental to:

- Web applications and APIs
- Cloud computing
- Distributed systems
- Infrastructure and Site Reliability Engineering (SRE)
- Network security and troubleshooting
